## 2026-08-19 - Dynamic Element Focus Styling Constraint\n**Learning:** In highly interactive client-side apps, essential accessibility classes (like `peer` for Tailwind's sibling focus styling) are often assigned programmatically within JavaScript components rather than statically in HTML, requiring code review tools and UI testers to trace element generation back to the source `createElement` calls.\n**Action:** When implementing sibling-based pseudo-class states (like `peer-focus-visible`), always verify the presence of the prerequisite `peer` class by examining the JavaScript DOM injection logic rather than relying solely on static HTML inspection.
